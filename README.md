# MORSE DECODER
---
I made a hermes project with the sensor, I kept it simple with only detected or not, instead of proximity values, so I could make it a morse decoder

### How it works
---
If input is less than 1.5 second it inputs dot, longer inputs dash, longer than 4 makes a space to end the input of ONE letter, longer than 6 ends the word
it then decodes it onto the screen, and plays back the code on the LED in morse, as well as plays functions that are added, as of now a simple play song by the code SONG, is added with simple buzzer noises
